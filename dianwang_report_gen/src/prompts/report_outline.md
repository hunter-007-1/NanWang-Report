#### 技术经济比较

(1)方案比选方法

<说明本报告采用“N-1通过率评价 -> 经济择优 -> 其他技术指标排序”的三阶段比选体系。阶段一只看N-1通过率，按 100% / &gt;95% / 90-95% / &lt;90% 区间描述各方案从N-1角度的可用性强弱；阶段二按经济成本排序；阶段三查看并排序其他技术指标，作为最终推荐的权衡依据。最终推荐主要参考阶段二经济排序。>

(2)阶段一：N-1通过率评价

<展示各方案N-1通过率。N-1通过率按区间评价：100%为最优，&gt;95%且&lt;100%为较优，90-95%为可用但需关注，&lt;90%为可用性较弱。>

<从N-1通过率角度说明各方案是否可用以及可用性强弱，例如说明方案在多数单一元件故障校核下具备供电连续性和运行适应性，但仍可能存在需关注故障场景。>

<若输入只有total_contingencies_run和contingencies_with_issues，应按(total_contingencies_run - len(contingencies_with_issues)) / total_contingencies_run * 100%计算N-1通过率；contingencies_with_issues非空时不得声称N-1通过率为100%。>

<若输入缺少N-1通过率，应说明当前输入不足以完成阶段一准入判断，不得编造通过率。>

<插入N-1通过率评价表，按方案列出N-1通过率、所处区间、可用性描述和需关注故障场景。不得将短路、电压、潮流指标写入阶段一评价。>

(3)阶段二：经济择优

<经济比较范围：对完成阶段一N-1通过率评价的方案开展经济择优。>

<核心指标：优先比较年费用，按数值从小到大排序，最低者优先。年费用按“年费用 = 建设投资成本 × i(1+i)^n / ((1+i)^n - 1) + 运维成本”计算，其中 n=20，i=0.07。>

<辅助指标：展示建设投资成本、运维成本，均按越低越优排序，用于解释成本构成。>

<数据约束：若输入数据未提供建设投资、运维成本、年费用或可明确计算费用的原始数据，不得生成经济表、费用公式或费用数值；应说明“当前输入未提供经济费用数据，无法完成阶段二经济择优排序”。>

<插入经济择优表，仅使用输入数据中真实存在或可明确计算的经济指标。阶段二按年费用排序，排序结果是最终推荐的主要依据。>

(4)阶段三：其他技术指标排序

<对阶段一通过方案的其他技术指标进行查看和排序，说明各方案技术指标与推荐值或推荐区间的接近程度。>

<短路电流类指标：比较短路裕度、短路电流水平、短路越限节点数、短路越限比例等。参考区间包括短路裕度 >8 / 5-8 / 2-5 / <2，短路电流水平低于极限20%以上为优，短路越限节点数 0 / 1-2 / 3-5 / >5，短路越限比例 0 / <1% / 1-3% / >3%。>

<电压水平指标：比较电压越限节点数、电压越限比例等。参考区间包括电压越限节点数 0 / 1-3 / 4-8 / >8，电压越限比例 0 / <2% / 2-5% / >5%。>

<潮流安全指标：比较线路重过载率、变压器重载率等。参考区间包括线路重过载率 <60 / 60-80 / 80-100 / >100，变压器重载率 <70 / 70-85 / 85-95 / >95。>

<若输入中存在其他技术指标，应按“越接近推荐值越优”的原则排序；若没有对应数据，应说明未提供，不得编造。>

<插入其他技术指标排序表，列出短路、电压、潮流等可用指标、推荐区间、各方案排序及排序依据。阶段三结果用于权衡阶段二经济排序，不作为阶段一淘汰依据。>

#### 综合比较推荐方案

<按三阶段比选逻辑进行综合评述：先说明阶段一N-1通过率评价中各方案所处区间和可用性强弱；再说明阶段二经济择优排序；最后说明阶段三其他技术指标排序如何影响或强化推荐结论。最终推荐主要参考阶段二，并权衡阶段一和阶段三结果。>

- 经济择优方面：<仅基于输入中存在的经济数据，对通过准入的方案进行排序；若经济数据缺失，应说明无法完成经济择优。>
- 其他技术指标方面：<对比短路、电压、潮流等指标与推荐值或推荐区间的接近程度，说明是否需要对经济排序进行权衡。>
- 工程建设性方面：<在有输入数据时，对比方案的施工难度、是否需停电配合等。>
- 与规划项目衔接方面：<在有输入数据时，对比方案与远期规划项目的衔接过渡能力。>
