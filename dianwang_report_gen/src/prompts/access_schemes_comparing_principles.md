## 接入方案三阶段比选体系

接入系统方案比选采用“N-1通过率评价 -> 经济择优 -> 其他技术指标排序”的顺序。报告必须先按 N-1 通过率区间评价各方案从 N-1 角度的可用性，再开展经济成本排序，最后查看并排序其他技术指标。最终推荐主要参考阶段二经济排序，并权衡阶段一 N-1 通过率评价和阶段三技术指标结果。

若输入包含“方案比选核心指标汇总表”，该表是核心排序指标的最高优先级来源。N-1通过率、N-1区间、最高N-1重载率、短路越限节点数、最大短路电流、建设投资成本、运维成本和年费用应优先从该表读取；明细表用于解释具体问题点，不用于推翻汇总表。

### 阶段一：N-1通过率评价

阶段一只看供电能力与运行适应性中的 N-1 通过率，并按区间评价方案从 N-1 角度的可用性强弱。

阶段一指标包括：

| 指标类别 | 具体指标 | 作用 | 判断逻辑 |
|:--|:--|:--|:--|
| 供电能力与运行适应性 | N-1通过率 | 阶段一可用性评价指标 | 100% / &gt;95% / 90-95% / &lt;90%，按区间描述可用性强弱 |

报告写法要求：

- 必须以表格展示各方案的 N-1 通过率及阶段一结论。
- N-1通过率为100%的方案，评价为最优，应说明所有单一故障场景均未出现需关注问题。
- N-1通过率大于95%且小于100%的方案，评价为较优，应说明仅有少量 N-1 问题，整体可用性较强。
- N-1通过率位于90%~95%的方案，评价为可用但需关注，应说明存在一定数量 N-1 问题，但仍可进入经济比选；90%和95%均归入该区间。
- N-1通过率低于90%的方案，评价为可用性较弱，应作为最终推荐的不利因素。
- 若输入只有 total_contingencies_run 和 contingencies_with_issues，应按 `(total_contingencies_run - len(contingencies_with_issues)) / total_contingencies_run * 100%` 计算 N-1 通过率；contingencies_with_issues 非空时不得声称 N-1 通过率为100%。
- 若已有“方案比选核心指标汇总表”，不得重新估算或改写其中的 N-1 通过率和区间。
- 不得将短路电流、电压偏移、线路/变压器重载等其他技术指标作为阶段一评价条件；这些指标放在阶段三排序。
- 若输入数据缺少 N-1 通过率，应说明“当前输入未提供N-1通过率，无法完成阶段一准入判断”，不得编造指标值。

### 阶段二：经济择优

阶段二是核心决策阶段，对完成阶段一 N-1 通过率评价的方案进行排序。

经济指标包括：

| 指标类别 | 具体指标 | 作用 | 判断逻辑 |
|:--|:--|:--|:--|
| 经济类 | 年费用 | 核心决策指标 | 越低越优，按数值从小到大排序 |
| 经济类 | 建设投资成本 | 辅助经济指标 | 越低越优，用于解释成本构成 |
| 经济类 | 运维成本 | 辅助经济指标 | 越低越优，用于解释成本构成 |

报告写法要求：

- 经济比较必须基于输入数据中真实存在的建设投资、运维成本、年费用或可由输入数据明确计算出的费用。
- 年费用按 `年费用 = 建设投资成本 × i(1+i)^n / ((1+i)^n - 1) + 运维成本` 计算，其中 `n=20`，`i=0.07`。
- 若输入数据没有经济数据，不得生成总投资、年运行费、年费用、全寿命周期成本或造价指标。
- 若经济数据缺失，应写明：“当前输入未提供建设投资、运维成本或年费用数据，无法完成阶段二经济择优排序。”
- 若只有部分经济数据，例如仅有建设成本或维护成本，应只比较已有字段，并说明不足以形成完整年费用排序。
- 阶段二排序是最终推荐的主要依据；阶段三只用于权衡和解释技术差异。
- 示例数据或历史工程数据只能用于说明方法，不得作为当前工程方案的数值来源。

### 阶段三：其他技术指标排序

阶段三用于查看并排序各方案的其他技术指标，说明方案在短路、电压、潮流等技术维度上的相对优劣。

技术辅助指标包括：

| 指标类别 | 具体指标 | 作用 | 判断逻辑 |
|:--|:--|:--|:--|
| 短路电流类 | 短路裕度 | 技术排序指标 | 按推荐区间排序：>8 / 5-8 / 2-5 / <2，越接近推荐值越优 |
| 短路电流类 | 短路电流水平 | 技术排序指标 | 低于极限20%以上为优；越接近安全推荐值越优 |
| 短路电流类 | 短路越限节点数 | 技术排序指标 | 按推荐区间排序：0 / 1-2 / 3-5 / >5 |
| 短路电流类 | 短路越限比例 | 技术排序指标 | 按推荐区间排序：0 / <1% / 1-3% / >3% |
| 电压水平 | 电压越限节点数 | 技术排序指标 | 按推荐区间排序：0 / 1-3 / 4-8 / >8 |
| 电压水平 | 电压越限比例 | 技术排序指标 | 按推荐区间排序：0 / <2% / 2-5% / >5% |
| 潮流安全 | 线路重过载率 | 技术排序指标 | 按推荐区间排序：<60 / 60-80 / 80-100 / >100 |
| 潮流安全 | 变压器重载率 | 技术排序指标 | 按推荐区间排序：<70 / 70-85 / 85-95 / >95 |

报告写法要求：

- 阶段三应对可用技术指标进行排序，说明每个方案处于推荐区间中的哪个档位。
- 阶段三不能替代阶段一 N-1 通过率评价；阶段一 N-1 可用性较弱的方案，应在最终推荐中体现为不利因素。
- 阶段三不能在无数据时编造裕度、越限比例、重载率或推荐区间。
- 若经济最优方案与其他方案技术指标差异不大，应保持推荐经济最优方案。
- 若经济最优方案存在明显技术短板，应明确说明短板及权衡理由，但最终推荐仍应说明主要依据来自阶段二经济排序。

### 综合推荐逻辑

综合推荐应按以下顺序表达：

1. 先说明阶段一 N-1 通过率评价结果：按 100% / &gt;95% / 90-95% / &lt;90% 区间描述各方案从 N-1 角度是否可用以及可用性强弱。
2. 再说明阶段二经济择优结果：按年费用、建设投资成本、运维成本或已有经济指标排序。
3. 最后说明阶段三其他技术指标排序：查看短路、电压、潮流等指标是否接近推荐值，并说明是否对经济排序形成权衡。
4. 推荐方案必须能追溯到输入数据。没有数据支撑的指标不能作为推荐依据。
