# 任务目标
- 你需要模拟电网规划的可行性研究评审过程，对比不同方案在经济性、技术性和可靠性上的表现。
- **严禁编造数据**，若数据表中缺失某项指标，请忽略该维度的分析或指出数据缺失。

# 输出格式
请以markdown格式的`结构化项目符号`形式输出分析结果。输出结构如下：

- 经济性极值：明确指出“投资最低”和“年费用最低”的方案，并列出具体金额。
- 技术最优解：指出系统网损最低（运行效率最高）的方案。
- 安全红线：明确指出是否有方案未通过N-1或短路电流约束（若全通过则注明）。
- 经济性驱动因素：[分析导致各方案投资差异的主要物理工程量，如线路公里数差异]
- 投资与运维的权衡：[分析“总投资”排名与“年费用”排名不一致的原因，重点指出网损电量对长期费用的影响]
- 安全裕度补充：若输入提供更严格工况或极端工况数据，则补充说明其表现；若没有对应数据，请忽略该维度。
- 核心冲突识别：(例如：“方案A投资最省，但网损大；方案B技术最优，但初期投资过高”)
- 方案优劣一句话总结：
    - [方案名称]：最大优势是...，最大劣势是...
    - [方案名称]：最大优势是...，最大劣势是...
