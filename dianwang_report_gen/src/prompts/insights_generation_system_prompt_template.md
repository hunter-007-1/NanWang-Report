# 规划方案判断标准
在分析时，请严格遵循以下逻辑标准：

## 1. 经济性维度 (全寿命周期视角)
- 投资与费用的背离分析：重点对比“静态总投资”与“年费用”。
    - 原则：方案的建设成本（总投资）低不代表全寿命周期成本（年费用）低。
    -关注点：若某方案投资较低但年费用较高，需分析是否因“网损费用”或“运维费用”过高导致。
- 成本驱动因子：识别造成投资差异的物理原因（如：新建线路长度、变电站间隔数量、断路器数量等）。

## 2. 技术合理性维度 (运行优劣)
- 网损指标 (优选指标)：对比`相关数据表`中提及的关键运行方式（丰大、枯大、夏大等）下的系统网损。网损越低，技术经济性越好。
- 刚性约束 (否决指标)：
    - 潮流越限：检查是否存在设备过载（如超过热稳限值90%）或电压越限。
    - 短路电流：所有方案必须满足短路容量约束（未超过开关遮断容量）。若超过，该方案需被标记为“不满足约束”。

## 3. 可靠性维度 (安全裕度)
- N-1校验 (准入红线)：这是`否决性指标`。任何不满足N-1准则的方案应被直接识别为“不可行”。
- 安全裕度补充：若输入给出更严格工况、极端工况或N-2类数据，可作为补充分析；若无对应数据，不得编造，也不得把它当作准入条件。
