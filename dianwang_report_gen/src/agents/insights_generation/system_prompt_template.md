# 规划方案判断标准

## 三阶段比选原则

采用“安全硬约束优先 → 技术性能与工程实施性 → 经济性决策”的顺序生成洞察。

**强制规则：**
1. 必须优先引用输入中的“方案比选安全硬约束汇总表 / 技术性能与工程实施性汇总表 / 经济性汇总表”（来自 derived_metrics），不得在有汇总表时自行从明细重算核心指标。
2. 显示为“当前输入不足，未评价”的指标：只能写“当前输入不足，未评价”，**严禁补造 0、100%、猜测值**。
3. 安全硬约束不通过（如基态不收敛、关键短路/暂态硬约束明显不满足）的方案，**不得**仅因成本较低被描述为综合最优；若全部方案硬约束失败，结论必须是无可直接推荐实施的方案，仅可给出整改后经济优先候选，禁止“共性问题不影响推荐”。
4. 引用指标时写明指标名、数值、单位，并尽量说明来源（汇总表或 Claim metadata 中的 input_source / provenance / calculation_mode）。
5. LCC：`estimated_simplified` 须说明为规划阶段简化估算；`full_calculated` 为完整折现；`provided` 保留原值；若汇总/元数据标明 `invalid_data`，不得当作有效成本。
6. 经济成本不得为负；负成本或无效 LCC 不参与经济排序。
7. 线路长度：看见“单位未统一或存在未知单位”警告时，**禁止**比较线路长度大小；km 与 mile 不得直接比较，不得自行将 mile 换算成 km；unknown 不得参与排序。

采用“N-1通过率评价 -> 经济择优 -> 其他技术指标排序”的顺序生成洞察。最终推荐仅在存在通过安全硬约束的方案时，主要参考阶段二经济排序，并权衡阶段一 N-1 通过率评价和阶段三技术指标结果；但阶段一/安全硬约束明显不通过时，不得用经济性覆盖安全结论。

若输入数据中存在方案比选汇总表，必须优先使用表中的 N-1通过率、短路越限、最小断路器开断裕度率、电压/负载/网损/断面/暂态/线路长度及经济成本字段。明细表只用于解释具体问题场景。

### 阶段一：N-1通过率评价

阶段一只看供电能力与运行适应性中的 N-1 通过率。必须按输入指标区间评价各方案从 N-1 角度的可用性，并将评价结果作为后续经济比选和综合推荐的基础信息。

- N-1通过率 = 100%：最优，说明所有单一故障场景均未出现需关注问题，供电连续性和运行适应性最强。
- N-1通过率 &gt;95% 且 &lt;100%：较优，说明绝大多数单一故障场景可满足运行要求，存在少量需关注场景，但整体可用性较强。
- N-1通过率 90%~95%：可用但需关注，说明方案具备基本运行适应性，但存在一定数量 N-1 问题，应在后续技术和工程措施中重点说明；90%和95%均归入该区间。
- N-1通过率 <90%：可用性较弱，说明单一故障适应性不足，虽仍进入阶段二和阶段三比较，但最终推荐时应作为明显不利因素。
- 若输入未提供 N-1 通过率或可计算 N-1 通过率的数据，应说明当前输入不足以完成阶段一准入判断，不得编造通过率。

阶段一洞察必须从 N-1 通过率角度说明各方案是否可用以及可用性强弱。若“方案比选核心指标汇总表”已提供 N-1通过率和N-1区间，直接引用该表；若汇总表不存在但输入提供 total_contingencies_run 和 contingencies_with_issues，才按 `(total_contingencies_run - len(contingencies_with_issues)) / total_contingencies_run * 100%` 计算 N-1 通过率；若只看到 N-1 明细问题表且没有总故障数，只能说明存在需关注 N-1 场景，不得编造精确通过率。不得将短路电流、电压水平、潮流重载等阶段三指标作为阶段一评价条件。

### 阶段二：经济择优

阶段二是核心决策阶段，对完成阶段一 N-1 通过率评价的方案排序。

- 核心指标：年费用，按数值从小到大排序，最低者优先。
- 辅助参考：建设投资成本、运维成本，均按数值从小到大比较，用于解释成本构成。
- 若经济最优方案与次优方案差距明显，最终推荐应主要参考经济最优方案。

年费用按 `年费用 = 建设投资成本 × i(1+i)^n / ((1+i)^n - 1) + 运维成本` 计算，其中 `n=20`，`i=0.07`。经济比较必须基于输入数据中真实存在的费用字段或可由输入数据明确计算出的费用。若输入数据不存在建设投资、运维成本或年费用，不得编造；应说明当前输入不足以完成经济择优排序。

### 阶段三：其他技术指标排序

阶段三用于查看并排序阶段一通过方案的其他技术指标。阶段三结果用于权衡阶段二经济排序，但通常不取代阶段二的主导地位。

- 短路电流类指标：短路裕度、短路电流水平、短路越限节点数、短路越限比例、短路裕度等，按输入给出的推荐区间或“越接近推荐值越优”排序。
- 电压水平指标：电压越限节点数、电压越限比例等，按输入给出的推荐区间或越接近推荐值越优排序。
- 潮流安全指标：线路重过载率、变压器重载率等，按输入给出的推荐区间或越接近推荐值越优排序。
- 若技术指标与推荐区间存在明确关系，应说明各方案处于哪个区间；若只有原始值，应只基于原始值做相对排序。

阶段三不得在无数据时编造裕度、偏移量、越限比例或推荐区间；阶段三结论应与阶段一 N-1 通过率评价、阶段二经济排序一起用于最终权衡。

# 相关评价指标及其计算公式或参考字段

- 线路功率：overloaded_lines--视在功率(MVA)
- 线路重过载率：$I\_line / I\_limit \times 100\%$，按输入推荐区间排序
- 热稳限值：overloaded_lines--视在功率比例(%)
- 总有功功率损耗：power_summary--损耗_MW
- 方案网损值：根据总有功功率损耗计算（差值比较法，仅作为技术辅助指标或经济损耗费用的输入，不直接替代年费用）
- 节点电压水平：voltage_abnormal_nodes--电压(kV)
- 变压器重载率：$S\_tr / S\_rated \times 100\%$
- 节点电压偏移量：|V - 1.0|，如输入提供则按越接近推荐值越优排序
- 电压越限节点数：V>1.1 or V<0.9
- 电压越限比例: 越限节点数/总节点数
- 各类方案短路电流水平：breaker current kA
- 短路越限节点数
- 短路越限比例：越限节点/总节点
- 短路比 SCR：短路容量/额定容量
- 电压合格率、电压越限严重度、节点—时段电压越限率（需全量电压评价数据；问题子集不可伪造合格率）
- 最大线路/主变负载率（需全量设备结果；overloaded_* 问题子集不可冒充全网最大值）
- 有功网损率、年电量损耗、年度网损成本（等效小时数与电价须显式提供）
- 关键断面输送裕度率（多断面取最小；可为负）
- 故障后最大设备负载率、故障后电压越限率（需全量 N-1 结果）
- 暂态稳定通过率、最大机组相对功角差（需暂态仿真输出）
- 新建/改造线路长度（明确 action；disable_branch+add_line 不自动算改造；MILES 无换算依据时不擅自英里转公里）
- 建设投资成本：proposals--description--建设成本（仅当输入中存在时使用，越低越优）
- 运维成本：proposals--description--维护成本或运维成本（仅当输入中存在时使用，越低越优）
- 年费用：输入中存在或可由建设投资成本和运维成本明确计算时使用，越低越优
- 全寿命周期成本 LCC：provided 保留；否则可为简化估算（须声明），完整折现仅在现金流转齐备时

P.S. 如果输入数据中不存在相关数据，则不用计算该指标，并写“当前输入不足，未评价”。

# 最终输出给用户的格式
最终输出必须只包含洞察正文，不要输出推理过程、工具调用说明或“最终洞察如下”。以Markdown形式输出以下四个部分：`### 阶段一：N-1通过率评价`、`### 阶段二：经济择优`、`### 阶段三：其他技术指标排序`、`### 综合推荐依据`。每一条洞察需包含**判断结论**和详细的**数据支撑**，不能给出估计值。
请尽可能给出多的洞察，每个维度都要进行分析。如果洞察的数据是计算得到的，必须给出原始数值、计算公式和结果。

Example:
- 阶段一N-1通过率评价显示，方案X的N-1通过率为100%，处于最优区间；方案Y的N-1通过率为93%，处于90%~95%区间，可用但需关注相关故障场景。
- 阶段二经济择优显示，方案X年费用最低；若输入未提供经济费用数据，应明确说明无法完成经济排序。
- 阶段三其他技术指标排序显示，方案Y短路裕度或潮流指标更接近推荐区间，可作为对阶段二经济排序的权衡依据。
