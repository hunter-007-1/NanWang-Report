# 任务二：报告生成

## 0. 比选分层原则（报告必须遵循）

网架规划方案比选采用“**安全硬约束优先 → 技术性能择优 → 全寿命经济性决策 → 辅助指标解释**”的分层原则：

1. **先判断安全硬约束**：基态潮流收敛性、N-1通过率、短路越限比例、最小断路器开断裕度率等。不满足硬约束的方案原则上**不进入经济排序**，更不得成为最终推荐。
2. **共性不等于可忽略**：若全部方案均违反安全硬约束，结论必须是“无可直接推荐实施的方案，需整改后重校”，仅可给出经济优先的整改候选；禁止“共性问题不影响推荐”。
3. **再比较技术性能**：电压、设备负载、网损、断面裕度等（在安全可行方案中择优）。
4. **最后比较经济指标**：年费用、全寿命周期成本 LCC 等；同一物理含义或可相互换算的指标只保留一个核心指标计分。
5. **关联指标不重复计分**：
   - N-1通过率 与 N-1负荷加权通过率 存在关联，不要重复计分；
   - 短路越限比例 与 最小断路器开断裕度率 同属短路维度，不要简单重复加分。
6. **缺数不编造**：缺少输入数据的指标必须明确写“当前输入不足，未评价”，不得用 0 或猜测值代替。
7. **第二批指标**（电压合格率/严重度/节点—时段越限率、最大线路与主变负载率、有功网损率、关键断面裕度率、故障后设备负载与电压越限率、暂态稳定通过率、最大功角差、新建/改造线路长度、年电量损耗与网损成本）须进入 derived_metrics，并在三张汇总表中展示；缺数同样不得编造。
8. **LCC**：
   - `provided`：保留原值，`formula=None`；须为有限非负数；
   - `estimated_simplified`：仅当**完全未提供**任何完整折现专用字段时，`LCC = construction_cost × factor`（默认 factor=1.25），须声明非完整折现；
   - `full_calculated`：仅在 `cash_flows`（非空列表）、`discount_rate`、`evaluation_years` 三类参数**全部提供且有效**时计算：
     `construction_cost + sum(cash_flow.cost / (1 + discount_rate) ** cash_flow.year)`；
   - 只要出现任意完整折现专用字段（含别名），即视为完整折现意图，必须校验完整性；部分提供、类型错误、空列表或内容错误 → `invalid_data`，**禁止**回退 `estimated_simplified`；无效 LCC 不参与经济排序；
   - `discount_rate` 必须有限且 `>= 0`（允许 0）；`evaluation_years` 有限且 `>= 0`（允许小数）；
   - 单笔现金流可为负（残值），最终 LCC 不得为负；坏记录不得静默跳过；
9. **经济成本非负**：`construction_cost` / `operation_cost` / `annual_cost` / `lifecycle_cost` / `factor` 均不得为负；负成本不进汇总有效列、不生成 Claim、不参与排序。
10. **线路长度单位**：`length_km`→km；`MILES`/`miles`→mile（原样求和、不做英里→公里）；同一方案 km 与 mile 混合时不得求和；汇总表显示 `km` / `mile` / `（单位未知）`；跨方案单位不统一或未知时禁止横向大小排序。
11. **经济显示与溯源**：汇总表与 claim 统一使用**元**；若报告正文使用亿元，必须用 `<calculate>` 做 `/100000000`，禁止用元 claim 包裹亿元数值。

| 技术指标 | 短路电流类指标 | 短路越限比例 | % | 硬约束指标 / 单调风险指标 | 0 / ＜1% / 1%～3% / ＞3%；越低越优 | `R_over = N_over / N_check * 100%`，`N_check` 取有效校核节点总数（如 `analysis.total_buses`）。缺少分母时比例显示“数据不足”，不得把越限节点数同时当作分子和分母。 | 越限比例越低越优。 | GB/T 15544.1-2023。 |
| 技术指标 | 电压水平指标 | 电压越限节点数 | 个 | 硬约束指标 / 单调风险指标 | 0 / 1～3 / 4～8 / ＞8；越少越优，关键节点严重越限时直接降级 | 通过规划水平年典型最大、最小负荷及新能源典型出力场景潮流计算，统计电压偏差超过规定范围的节点：`N_U = sum(1(U_i < U_i,min or U_i > U_i,max))`。同一节点在多个时段越限，节点数只计一次，另建议补充“越限节点-时段数”和最大偏差值。 | 越限节点数越少越优；关键节点严重越限时直接降级或要求整改。 | GB/T 12325-2008《电能质量 供电电压偏差》；DL/T 5729-2023。 |

| 技术指标 | 潮流安全指标 | 变压器重载率 | % | 目标区间型指标 | ＜70% / 70%～85% / 85%～95% / ＞95%；70%～85% 为推荐区间，＞100% 不合格 | `eta_T,i = max_t(S_i,t / S_N,i) * 100%`，其中 `S_N` 为主变额定容量。对并列主变应按实际分列或并列方式分别计算；N-1 场景下还应计算故障转供后的应急负载率。建议区分“正常运行负载率”和“N-1 应急负载率”，并统计持续时间，避免以短时峰值直接判定长期过载。 | 优先选择推荐区间内方案；过低可能代表设备利用率不足，过高代表运行裕度不足，超过允许承载能力时直接淘汰。 | DL/T 5729-2023；变压器是否允许短时过载还应依据具体设备技术条件、温升及负载导则。 |
| 技术指标 | 安全稳定指标 | 安全稳定计算结果 | 频率、电压、潮流、功角等 | 硬约束指标 | 以稳定/失稳判据为准；失稳方案原则上不合格 | 按安全稳定计算导则对频率、电压、潮流、功角等稳定性指标进行校核。当前规则保留为待细化项，需结合仿真输出定义具体输入、公式和判据。 | 稳定为基本约束；若出现失稳，应判为不合格或整改后重新评价，不得通过经济指标补偿。 | GB 38755-2019《电力系统安全稳定导则》等相关标准。 |

> 注：若某项指标在输入数据中不存在，不能编造结果；应说明当前输入不足以完成该指标比较。经济类指标以实际能算出结果为准，所有方案必须采用相同计算口径。`annual_cost`（年费用）与 `lifecycle_cost`（LCC）必须分列，禁止互为回退。

## 2. 不同类型指标的比较方式

| 指标类型 | 区间内如何选择 | 低于推荐区间如何处理 | 高于推荐区间如何处理 |
| -------- | -------------- | -------------------- | -------------------- |
| 硬约束指标 | 满足安全限值后，再按裕度大小或越限数量排序 | 对通过率、裕度类指标，低于推荐区间表示安全储备不足，应降级或整改 | 超过设备能力、允许电压或承载限值时，直接判定不合格，不得通过经济指标补偿 |
| 成本指标 | 在满足技术约束的方案中，实际成本越低越优 | 成本异常低时，检查是否漏项、少建或降低建设标准 | 成本高于推荐区间时，只有在技术收益能够合理覆盖增量成本时才保留 |
| 单调裕度指标 | 如短路裕度、N-1 通过率，向更优方向越大越好 | 低于推荐区间表示适应性和安全储备不足 | 高于最优区间可按最优等级计，不建议无限增加得分 |
| 单调风险指标 | 如越限节点数、越限比例，数值越低越好 | 低于区间下限通常表示更优，可按最优等级计 | 一旦达到越限或不合格范围，应整改后重新评价 |
| 目标区间型指标 | 如线路、变压器负载率，优先选择推荐区间内方案 | 过低可能代表设备利用率不足或过度建设，应结合投资筛选 | 过高代表运行裕度不足；超过允许承载能力时直接淘汰 |

## 3. 后续结构化要求

- 需要从每个指标中明确解析：指标名称、公式、输入、输出、单位、比较方向、分档和参考出处。
- 已结构化到 `src/skills/resources/compare_rules.yaml` 的指标，可由 `grid_calculator` 进行确定性计算。
- 尚未明确输入字段或判据的指标，应保留为规则说明，不应让模型自行编造计算结果。
