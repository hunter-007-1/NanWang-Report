> 结构化比选规则与公式以 `src/skills/resources/compare_rules.yaml` 及同目录 `compare_rules.md` 为准（含 LCC 三模式、`discount_rate>=0`、完整参数无效禁止回退简化估算、经济成本非负、线路长度 km/mile/单位未知及跨方案禁止横向排序）。本文件为历史摘要，请勿单独作为实现依据。

| 技术指标 | 短路电流类指标 | 短路越限节点数 | 个 | 单调风险指标 | 0 / 1～2 / 3～5 / ＞5；越少越优，非零方案整改后重新评价 | 对全部纳入评价的母线、开关站和变电站进行短路校核。当 `I_sc,i > I_allow,i`，或短时耐受、峰值耐受不满足时，该节点计为越限。`N_over = sum(1(I_sc,i > I_allow,i))`。同一节点在多个运行方式越限时原则上只计一个节点，并在附表中列出最严重方式。 | 越限节点数越少越优；非零时应说明越限位置和整改措施，必要时整改后重新评价。 | GB/T 15544.1-2023；允许值取相关断路器、母线、互感器及开关设备铭牌额定值，并符合 GB/T 1984-2024、GB/T 11022-2020。 |
| 技术指标 | 短路电流类指标 | 短路越限比例 | % | 硬约束指标 / 单调风险指标 | 0 / ＜1% / 1%～3% / ＞3%；越低越优，与越限节点数取较差等级 | `R_over = N_over / N_check * 100%`，其中 `N_check` 为全部有效校核节点数。不同方案必须采用相同节点范围和运行方式；建议同时给出按电压等级分组的越限比例，避免大量低压节点稀释高压关键节点的越限风险。 | 越限比例越低越优；与越限节点数取较差等级。标准层面的合格要求应为不得超过设备额定能力。 | GB/T 15544.1-2023；GB/T 1984-2024；GB/T 11022-2020。比例分档为项目评价规则，不是标准规定的安全允许值。 |
| 技术指标 | 电压水平指标 | 电压越限节点数 | 个 | 硬约束指标 / 单调风险指标 | 0 / 1～3 / 4～8 / ＞8；越少越优，关键节点严重越限时直接降级 | 通过规划水平年典型最大、最小负荷及新能源典型出力场景潮流计算，统计电压偏差超过规定范围的节点：`N_U = sum(1(U_i < U_i,min or U_i > U_i,max))`。同一节点在多个时段越限，节点数只计一次，另建议补充“越限节点-时段数”和最大偏差值。 | 越限节点数越少越优；关键节点严重越限时直接降级或要求整改。 | GB/T 12325-2008《电能质量 供电电压偏差》；DL/T 5729-2023。 |
| 技术指标 | 电压水平指标 | 电压越限比例 | % | 硬约束指标 / 单调风险指标 | 0 / ＜2% / 2%～5% / ＞5%；越低越优，结合越限幅度和持续时间评价 | `R_U = N_U / N_node * 100%`。若拥有全年时序数据，建议采用更稳定的“节点-时段越限率”：`R_U,t = N_over,node-time / (N_node * N_time) * 100%`。限值应按节点标称电压和用户类别分别配置，不能全部使用同一上下限。 | 越限比例越低越优；应结合越限幅度、持续时间和关键节点属性评价。 | GB/T 12325-2008；DL/T 5729-2023。 |
| 技术指标 | 潮流安全指标 | 线路重过载率 | % | 目标区间型指标 | ＜60% / 60%～80% / 80%～100% / ＞100%；60%～80% 为推荐区间，过低可能冗余，过高运行裕度不足 | 对每条线路计算最大负载率：`eta_L,i = max_t(abs(I_i,t) / I_i,allow,t) * 100%`，或采用视在功率口径 `abs(S) / S_allow`。架空线路允许载流量应考虑环境温度、风速和导线温升；电缆应考虑敷设方式、土壤热阻和并列修正。方案总指标建议同时统计最大值、P95 值及各分档线路数量。 | 优先选择推荐区间内方案；低于推荐区间可能代表利用率不足或过度建设，高于推荐区间代表运行裕度不足，超过允许承载能力时直接淘汰。 | DL/T 5729-2023《配电网规划设计技术导则》。 |
| 技术指标 | 潮流安全指标 | 变压器重载率 | % | 目标区间型指标 | ＜70% / 70%～85% / 85%～95% / ＞95%；70%～85% 为推荐区间，＞100% 不合格 | `eta_T,i = max_t(S_i,t / S_N,i) * 100%`，其中 `S_N` 为主变额定容量。对并列主变应按实际分列或并列方式分别计算；N-1 场景下还应计算故障转供后的应急负载率。建议区分“正常运行负载率”和“N-1 应急负载率”，并统计持续时间，避免以短时峰值直接判定长期过载。 | 优先选择推荐区间内方案；过低可能代表设备利用率不足，过高代表运行裕度不足，超过允许承载能力时直接淘汰。 | DL/T 5729-2023；变压器是否允许短时过载还应依据具体设备技术条件、温升及负载导则。 |
| 技术指标 | 安全稳定指标 | 安全稳定计算结果 | 频率、电压、潮流、功角等 | 硬约束指标 | 以稳定/失稳判据为准；失稳方案原则上不合格 | 按安全稳定计算导则对频率、电压、潮流、功角等稳定性指标进行校核。当前规则保留为待细化项，需结合仿真输出定义具体输入、公式和判据。 | 稳定为基本约束；若出现失稳，应判为不合格或整改后重新评价，不得通过经济指标补偿。 | GB 38755-2019《电力系统安全稳定导则》等相关标准。 |

> 注：若某项指标在输入数据中不存在，不能编造结果；应说明当前输入不足以完成该指标比较。经济类指标以实际能算出结果为准，所有方案必须采用相同计算口径。

## 2. 不同类型指标的比较方式

| 指标类型 | 区间内如何选择 | 低于推荐区间如何处理 | 高于推荐区间如何处理 |
| -------- | -------------- | -------------------- | -------------------- |
| 硬约束指标 | 满足安全限值后，再按裕度大小或越限数量排序 | 对通过率、裕度类指标，低于推荐区间表示安全储备不足，应降级或整改 | 超过设备能力、允许电压或承载限值时，直接判定不合格，不得通过经济指标补偿 |
| 成本指标 | 在满足技术约束的方案中，实际成本越低越优 | 成本异常低时，检查是否漏项、少建或降低建设标准 | 成本高于推荐区间时，只有在技术收益能够合理覆盖增量成本时才保留 |
| 单调裕度指标 | 如短路裕度、N-1 通过率，向更优方向越大越好 | 低于推荐区间表示适应性和安全储备不足 | 高于最优区间可按最优等级计，不建议无限增加得分 |
| 单调风险指标 | 如越限节点数、越限比例，数值越低越好 | 低于区间下限通常表示更优，可按最优等级计 | 一旦达到越限或不合格范围，应整改后重新评价 |
| 目标区间型指标 | 如线路、变压器负载率，优先选择推荐区间内方案 | 过低可能代表设备利用率不足或过度建设，应结合投资筛选 | 过高代表运行裕度不足；超过允许承载能力时直接淘汰 |

## 3. 后续结构化要求

- 需要从每个指标中明确解析：指标名称、公式、输入、输出、单位、比较方向、分档和参考出处。
- 已结构化到 `src/skills/resources/compare_rules.yaml` 的指标，可由 `grid_calculator` 进行确定性计算。
- 尚未明确输入字段或判据的指标，应保留为规则说明，不应让模型自行编造计算结果。
